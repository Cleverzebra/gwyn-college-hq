# Gwyn's College HQ

Family college-visit planning site.

- `index.html` - the front page: today's task, the daily calendar, visit bookings, from-home interviews, application links, and the college list.
- `planner.html` - the visit rubric, visit-day checklist, and debrief forms (entries save in the visitor's own browser).

Built from the home college-search workspace; updated by Claude Code sessions on request.
